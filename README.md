# NUC Display Lab

A proposed volunteer-friendly Linux display diagnostic and test toolkit for
Intel NUC systems with onboard DisplayPort-to-HDMI converters, initially the
NUC7i7BNH and its suspected MegaChips MCDP2800 LSPCON.

The goal is to establish whether byte-preserving TV-led Dolby Vision output can
be implemented in LibreELEC-yblod on this hardware.

**Status:** planning only. No tools, bootable image, or working NUC DV support
have been implemented. The project owner does not have the hardware; volunteers
will perform physical tests.

Start with [PLAN.md](PLAN.md). It contains the implementation sequence, evidence,
local source references, and instructions for resuming in a new session.
